AWS 인프라 프로비저닝

VPC 안에서 Public/Private Subnet을 분리하고, 트래픽 진입·아웃바운드·관리 접근 경로를 전부 코드로 설계했다.

1
격리 — Private + SSM 전 노드 Public IP·SSH inbound 제거, SSM Endpoint로 내부망 전용 접속
2
아웃바운드 — NAT Instance NAT Gateway(월 $42) 대신 t3.micro EC2로 저비용 아웃바운드 중계
3
인바운드 — Reverse Proxy Nginx가 유일한 진입점, NodePort는 Proxy SG 출처로만 개방
4
가용성 — CP 3대 + 내부 NLB etcd 정족수 고려, NLB로 고정 엔드포인트를 제공해 CP 장애에 대비
5
경계 방어 — NACL Public Subnet 경계에서 악성 IP를 Reverse Proxy 도달 전에 차단
